# FactuFast React

Aplicación web de facturación e inventario desarrollada con React y conectada a un backend PHP/MySQL.

## Características principales

- Registro y gestión de facturas
- Control de clientes, productos y proveedores
- Anulación de facturas con cierre de ventana emergente
- Reportes de ventas y ganancias
- Panel de administración y navegación por roles

## Estructura del proyecto

- src/pages: vistas principales de la aplicación
- src/components: componentes reutilizables
- src/layout: estructura de diseño del panel
- archive: respaldos y archivos antiguos

## Requisitos

- Node.js
- npm
- XAMPP o servidor local con PHP y MySQL

## Instalación

1. Clona el repositorio
2. Instala dependencias:
   ```bash
   npm install
   ```
3. Inicia la aplicación:
   ```bash
   npm start
   ```

## Variables de entorno

La app usa la API local del backend en:

- http://localhost/factufast-api

## Notas

Este repositorio incluye una carpeta de respaldo para archivos antiguos y versiones previas del proyecto.
